Thanks to everyone who attended the conference! If you couldn’t make it to Helsinki this year or just want to watch some of the amazing talks again, videos can be found on Robot Framework’s Youtube channel.

RoboCon is the first, annual, gathering for the Robot Framework community. It provides a great possibility to learn from the experts, hear how the framework is used in different places, and, most importantly, meet fellow Robot Framework users as well as its developers.

Date: 18.1.2018, klo 09:00 – 18:00
Place: Valkoinen sali, Aleksanterinkatu 16-18, 00170 Helsinki

RoboCon is organized by Robot Framework Foundation, a non-profit consortium that also sponsors the development of Robot Framework. Possible profits from the conference will be used for this purpose too.

Hallway track

– – –

In addition to the main conference room, there is dedicated space for an official “hallway track”. There you can chat with other users, show demos, work together, organize ad-hoc open space sessions, meet sponsor companies, and so on. This space can be used between the presentations, but it’s fine to use it also during presentations that aren’t so relevant for you.

Sauna and dinner

Sauna and dinner

We start the conference activities with sauna, swimming and dinner at Allas Sea Pool on Wednesday, January 17.

Sauna and swimming starts at 6pm. The sauna that is reserved for us is mixed and swimsuit is obligatory. In addition to that, there are separate public saunas for men and woman. The open air swimming pool at the harbour in the heart of Helsinki is magnificent. Don’t worry the weather possibly being cold as the water is warm (except for the cold seawater pool for the brave).

After getting fresh at the sauna we continue with a dinner at the same premises at 8pm.

Sauna is free of charge for conference participants, but there’s only room for 40 people. Possible friends and family members can buy normal tickets if they want to join. Dinner is on own costs, except for conference speakers, and you need to select a set menu beforehand. Dinner is open for everyone and has same 40 people limit as sauna.

Registration for sauna and dinner opens during the first week of 2018. Conference participants will be informed about the exact time beforehand.

Sprints

Sprints

After the main conference we still have Friday, January 19, dedicated for development sprints. This event is for those who’d like to contribute to Robot Framework or any library or tool in its ecosystem. The event is free and open for everyone, including those not participating the conference itself. Sprint facilities are provided by Eficode and the address is Pohjoinen Rautatiekatu 25. Food and drinks will be available.

Agenda:
10:00 Welcome words. Introduction to participating projects and tasks they have available.
10:30 Introduction to contributing to open source projects. Git and GitHub introduction. Those familiar with these topics can skip this.
11:00 Development! Participants can work with tasks they find interesting either alone, in pairs, or in small groups. Project leaders help as much as they can.
16:00 Presenting what we have accomplished.
17:00 Official program ends. Sauna opens. Coding continues.

Confirmed project represented in the sprints are Robot Framework (Pekka Klärck), SeleniumLibrary (Tatu Aalto) and Jenkins plugin (Tatu Kairi and others), but it is also possible to work with other projects and even start totally new ones. If you have a project you’d like others to work with, please send an email to info@robocon.io and we can add it here. Especially with new projects, consider also presenting the project to others in lighting talks during the conference.

Developers from the aforementioned projects will select issues suitable for new contributors beforehand, but participants can obviously select issues they’d like to work with themselves. Many of the tasks are likely to involve coding, but there certainly are also non-coding tasks like testing and documentation.
